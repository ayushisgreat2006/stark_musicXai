# 🤖 SpotifyX Musix Bot

A powerful Telegram bot for downloading YouTube content, generating AI media, and more!

## ✨ Features

- **YouTube Downloads**: MP3, 360p-1080p videos
- **AI Chat**: Powered by Groq (20 queries/day)
- **AI Images**: Flux-pro generation
- **AI Videos**: Veo 3.1 Fast generation
- **Lyrics Search**: Get song lyrics instantly
- **Credit System**: Daily limits with referral bonuses
- **Premium Support**: Up to 450MB files
- **Admin Panel**: Broadcast, stats, user management
